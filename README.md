# 🚀 My MERN Stack Learning Journey

> This repository is my personal learning diary where I document and store **everything I've learned** during my web development journey — from the basics of HTML & CSS to full-stack MERN applications.

## 📚 What's Inside

| Folder | Description |
|---|---|
| `HTML/` | HTML fundamentals, semantic tags, forms, tables, and practice sets |
| `CSS CHAPTER/` | CSS styling, Flexbox, Grid, animations, and responsive design |
| `Javascript/` | JavaScript concepts, DOM manipulation, ES6+, and algorithms |
| `APNA College/` | Notes and practice problems from Apna College course |
| `Frontend practice/` | Mini frontend projects and UI practice |
| `React-project/` | React.js projects and component-based UI development |
| `backend/` | Node.js, Express.js, REST APIs, EJS templating, and MongoDB |
| `MajorProject/` | Full-stack MERN major project (Airbnb-style listing app) |
| `modern web page/` | Modern responsive web page designs |
| `projects/` | Mini projects including Spotify clone, cricket info, todo app |
| `untitled folder/` | Personal portfolio page |
| `figma/` | Figma to HTML/CSS conversion practice |
